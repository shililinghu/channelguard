ChannelGuard 0.1.4 已知限制

1. 系统进程分流支持能归属 PID 的新 TCP / UDP 连接，已有连接不会迁移。规则加载与已实测出口分开显示。
2. 系统分流不是独立 Kill Switch：宿主或界面退出后普通应用恢复系统网络。匹配应用在核心暂停/失效但分流宿主仍运行时阻断或连接失败。
3. 系统 DNS 代查、无法归属进程的连接、虚拟机 NAT、其他加速器/VPN驱动流量不保证逐应用接管。MuMu 内部游戏、雷神驱动仍需实际验证。
4. 父进程继承仅在祖先进程仍存在且可查询时有效；独立服务、退出启动器后的游戏应加入安装目录。未来新游戏库要重新识别或添加目录。
5. 目录规则覆盖所有内部 EXE，精确 EXE 优先。不是按 PID / 命令行隔离；共享 node.exe 路径会影响其全部实例。
6. UDP 仅在系统分流所用信道明确启用，HTTP / SSH 上游会拒绝此模式。默认浏览器模式仍限制 UDP，信道目前拒绝 IPv6 目标。
7. 普通 EXE 网络接管不会改变系统时区、语言、定位权限或硬件指纹。独立浏览器环境也不是完整反指纹内核；字体、GPU、Canvas、TLS、账户历史仍可被观察。
8. 游戏和反作弊兼容性未逐款测试。不修改或注入游戏进程，不提供反作弊绕过。若冲突请停用该应用分流。
9. 外部 VPN 必须允许所选直连内核真正绕过。只选择 Wi-Fi 网卡不能保证独立公网出口。直连公网 IP 可能在运营商地址池内变化。
10. 本版不叠加系统分流、旧 TUN 或旧管理员直连阻断。临时防火墙规则只限宿主的两项中继端口，正常停止清理；异常断电可能残留需检查。
11. 程序本身未代码签名，系统驱动使用官方签名 WinDivert 版本；未进行独立安全审计。退出会关闭工具启动的受管核心/浏览器，原有外部应用不关闭。
12. WSL OpenClaw 支持 Ubuntu 现有用户级 systemd 服务和 WSL2 NAT。工具关闭后服务仍运行但其配置代理不可用；打开后恢复桥。原始 TCP 或覆盖代理的插件需另外检查。
13. 自动检测每 30 秒扫描网络，每 5 分钟通过活动信道检查公开 IP/地区。不是持续的 DNS / WebRTC 外部审计。多个候选或缺少 VPN 时暂停，不猜测绑定。
14. 地区环境变化时受管浏览器需关闭后重新初始化。普通浏览器窗口的环境不会因此改变；IP 地理库也可能存在误差。
15. 无海外 VPS 节点的真实验收；不提供 IP 信誉隐藏或住宅 IP 转换。订阅自动更新、多跳链、通用系统服务接管、Windows 开机常驻服务尚未实现。

16. UDP 中继为每个客户端建立独立 SOCKS 会话，上限 256 个，空闲 60 秒清理。容量满时拒绝新 UDP 会话。当前同一 UDP 本地端口同时访问多个远端的场景仍受连接跟踪限制，迟到回复可能丢弃；不保证所有游戏、语音和加速器协议兼容。
